# Plan to Eat - PC1 Web Applications

## Description
This is a frontend web application developed for Plan to Eat, LLC. It consumes a public API to display a responsive recipe book. The project demonstrates the use of a domain-driven architecture, component-based design, and object-oriented programming patterns.

## Features
* **Recipe Book View:** Displays recipes in a responsive grid (two cards per row).
* **Internationalization (i18n):** Supports English  and Spanish languages via a toggle button.
* **API Integration:** Fetches real-time data from SampleAPIs using Axios.
* **Data Transformation:** Uses an Assembler pattern to map raw JSON data into clean domain entities.
* **Responsive UI:** Built with PrimeVue components and PrimeFlex for responsive design.

## Dependencies
* Vue 3.5 (Composition API)
* Vite
* PrimeVue 3 & PrimeFlex
* Axios
* Vue-i18n
